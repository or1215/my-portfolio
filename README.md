# My Portfolio - 作成物管理

自身のスキル、経験、およびこれまでのプロジェクトを網羅したポートフォリオサイトの管理リポジトリです。

## 🚀 プロジェクト概要
このプロジェクトは、フルスタックエンジニアとしての技術スタックを証明し、開発したアプリケーションやクラウドインフラの実績を視覚的に提示することを目的としています。

## 🛠 技術スタック
- **Frontend:** HTML5, CSS3 (Mobile First Design), JavaScript
- **Deployment:** Render / GitHub Pages
- **Tools:** Git, Markdown, JSON (Data Management)

## 📁 ディレクトリ構成
```text
.
├── index.html          # メインページ
├── css/                # スタイルシート（レスポンシブ対応）
├── js/                 # フロントエンドロジック
├── data/               # プロジェクト情報（JSON形式）
└── docs/               # 設計ガイドライン・マニュアル
