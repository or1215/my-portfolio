# 🧱 コンポーネント実装仕様 (Header Component)

このドキュメントは、Web Componentsを使用したヘッダーパーツの技術構成とデータ連携の仕様を定義したものです。

---

## 2. 技術スタック & 構造

### 🛠 使用技術
* **Custom Elements**: `class CustomHeader extends HTMLElement` を使用。
* **ES Modules**: `import/export` による外部ファイル（config.js）との連携。
* **Shadow DOM**: 未使用（グローバルCSSである `header.css` を適用させるため）。

### 📂 依存関係
* **Data Source**: `assets/js/common/config.js`
* **Styles**: `assets/css/header.css`

---

## 3. プロパティ・データ管理

ヘッダー内の定数データは、保守性を高めるため外部ファイルで一括管理します。

### 📄 config.js の定義
| 定数名 | プロパティ | 説明 |
| :--- | :--- | :--- |
| `CONTACT_INFO` | `email` | お問い合わせ先のメールアドレス |
| | `label` | ボタンに表示するテキスト（例: Contact） |

---

## 4. レンダリング仕様

`connectedCallback()` 内で以下のHTML構造を生成します。

### 🏗 HTML 構造 (DOM)
1.  **Header Container**: `.c-header`
2.  **Logo Area**: `.c-header__logo` (Top-level link)
3.  **Nav Control**: 
    * `input#nav-input`: メニュー開閉状態を管理するチェックボックス（非表示）。
    * `label#menu-btn`: ハンバーガーボタンのクリック領域。
4.  **Navigation Items**: 
    * `.c-nav`: PC/スマホ共通のコンテナ。
    * `.c-nav__link`: ページ内アンカーリンク。
    * `#contact-input`: お問い合わせ実行用のトリガーボタン。

---

## 5. イベント・アクション仕様

### 🖱️ メール送信フロー (JS Logic)
お問い合わせボタンクリック時に、誤操作防止のための確認プロセスを実行します。

1.  **イベントの紐付け**: `id="contact-input"` に対して `click` イベントを登録。
2.  **確認ダイアログ**: `window.confirm()` を呼び出し、ユーザーの意思を確認。
3.  **実行**: `isConfirmed` が `true` の場合、`window.location.href = mailto:...` を呼び出しメーラーを起動。

---

## 6. CSS 変数との連携

コンポーネントの高さや色は、`:root` で定義された変数を参照します。

* `--header-height`: ヘッダーの高さ（スクロール制御に使用）。
* `--white`: 背景色。
* `--transition-speed`: ホバー時のアニメーション速度。
