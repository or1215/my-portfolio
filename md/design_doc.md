# 🚀 エンジニア・ポートフォリオ 画面設計書

本ドキュメントは、自己紹介および学習成果の可視化を目的としたポートフォリオサイトの設計指針である。

* **目的**: 
    * 技術スタックの可視化
    * エンジニアとしてのマインドセットの提示
* **ターゲット**: 採用担当者、技術コミュニティ
* **デザイン指針**: 
    * `Simple` / `Clean` / `Modern`
    * マルチデバイス対応（Responsive）

## 3. 📱 レスポンシブ設計方針
デバイスの画面幅に応じた動的レイアウト最適化を行う。

### ■ モバイル版 (Smartphone)
> **ブレイクポイント: 767px 以下**
* **レイアウト**: 1カラム（縦一列）構成。
* **操作性**: タップしやすいボタンサイズ、縦並びメニュー。
* **余白**: 左右 15px〜20px のパディングでコンテンツの視認性を確保。

### ■ デスクトップ版 (PC)
> **ブレイクポイント: 768px 以上**
* **レイアウト**: 多カラム（Grid/Flex）構成。
* **ナビゲーション**: ヘッダー右上に横並び。
* **視覚効果**: ホバーアクション（マウスを乗せた時の動き）を追加。
* **最大幅**: コンテンツエリアを 1200px に制限し、視線移動を最適化。

## 4. 🛠️ 技術仕様
* **構造 (Markup)**: `HTML5` (Semantic Tagsを使用)
* **装飾 (Styling)**: `CSS3` (Flexbox, CSS Grid, Media Queries)
* **公開基盤 (Hosting)**: `GitHub Pages`
* **バックエンド実行環境**: `AWS Amplify` (成果物公開用)
